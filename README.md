# Домашнє завдання #8. NoSQL бази даних (MongoDB, Redis) та черги повідомлень (RabbitMQ)

Цей проєкт складається з двох основних частин, включаючи завдання підвищеної складності:
1. **Частина 1:** Робота з хмарною базою даних MongoDB Atlas через ODM Mongoengine, реалізація пошуку цитат із регулярними виразами та швидким кешуванням результатів через Redis.
2. **Частина 2:** Організація асинхронної розсилки повідомлень за допомогою черг RabbitMQ із розподіленням контактів на окремі канали (Email та SMS) та обробкою різними воркерами.

---

## 🛠️ Технологічний стек
* **Бази даних:** MongoDB Atlas (Cloud), Redis (Docker)
* **Черги повідомлень:** RabbitMQ (Docker)
* **ODM/Драйвери:** `mongoengine`, `redis`, `pika`, `psycopg2-binary`, `certifi`
* **Генерація даних:** `faker`

---

## 🚀 Як розгорнути та запустити проєкт локально

### 1. Налаштування середовища та запуск Docker-контейнерів
Переконайтеся, що Docker Desktop запущено. Виконайте в терміналі команди для запуску Redis та RabbitMQ:
```bash
# Запуск сервера кешування Redis
docker run --name some-redis -p 6379:6379 -d redis

# Запуск брокера повідомлень RabbitMQ
docker run -d --name some-rabbitmq -p 5672:5672 -p 15672:15672 rabbitmq:3-management
```

### 2. Встановлення бібліотек
```bash
pip install mongoengine python-dotenv certifi redis pika faker
```

### 3. Налаштування файлу `.env`
Створіть файл `.env` у корені проєкту та вкажіть ваш секретний рядок підключення до MongoDB Atlas:
```env
MONGO_URI=mongodb+srv://paulyskorbin_db_user:AZ3YSUs9DRE5yGn5@cluster0.zvtlk95.mongodb.net/homework8?retryWrites=true&w=majority
```

## 🔍 Інструкція до Частини 1: Пошук цитат із кешуванням

1. **Імпорт тестових даних:** Запустіть скрипт, який очистить базу та завантажить авторів і цитати з JSON-файлів у хмару MongoDB Atlas:
   ```bash
   python seed.py
   ```
2. **Інтерактивний пошук:** Запустіть CLI-програму пошуку:
   ```bash
   python search.py
   ```
   * Програма підтримує скорочення за регулярними виразами (наприклад, `name:st` знайде *Steve Martin*, а `tag:li` знайде *life*).
   * При повторному введенні тієї ж команди дані миттєво підтягнуться з оперативної пам'яті **Redis** із позначкою `⚡ [Взято з КЕШУ Redis]`.

## ✉️ Інструкція до Частини 2: Черги повідомлень RabbitMQ

Для повноцінного тестування асинхронної обробки відкрийте **три окремі вкладки терміналу** у вашій IDE:

1. **У першому терміналі** запустіть воркер для обробки Email-повідомлень:
   ```bash
   python consumer_email.py
   ```
2. **У другому терміналі** запустіть воркер для обробки SMS-повідомлень:
   ```bash
   python consumer_sms.py
   ```
3. **У третьому терміналі** запустіть продюсер, який згенерує 20 випадкових контактів через `Faker`, збереже їх у базу та розподілить їхні ID за відповідними чергами:
   ```bash
   python producer.py
   ```

Ви побачите, як у перших двох терміналах воркери миттєво перехоплюють повідомлення, імітують відправку («функція-заглушка») та змінюють статус контакту в MongoDB Atlas (`is_sent = True`).
